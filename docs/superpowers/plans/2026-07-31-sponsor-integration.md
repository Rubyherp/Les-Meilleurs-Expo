# Sponsor Integration Implementation Plan
> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development (recommended) or superpowers:executing-plans.

**Goal:** Implement the GMI Cloud, Agnes, OpenAI Agents, and Zo Computer integrations described in `docs/SPONSOR_INTEGRATION_PLAN.md` while preserving deterministic analysis and transparent fallback behavior.

**Architecture:** Add shared provider/evidence contracts first, then isolate each sponsor behind a backend adapter. Persist MVP metadata in `AnalysisResult.result_metadata`; expose the combined report through the existing coaching API; add mobile parsing and provenance UI only after backend contracts stabilize. GMI Serverless Inference is an independent evidence-grounding audit with optional GPU Compute provenance, Agnes is bounded image review, OpenAI is typed coaching orchestration, and Zo is an idempotent export.

**Tech Stack:** Python 3.12, FastAPI, Pydantic v2, SQLAlchemy JSONB, Celery, OpenAI Python SDK plus `openai-agents`, HTTPX, pytest; Expo SDK 54, React Native, TypeScript, Zustand.

## Global Constraints

- Use `docs/SPONSOR_INTEGRATION_PLAN.md` as the product source of truth.
- Deterministic measurements remain authoritative; models may summarize but may not overwrite measured values.
- Missing credentials are `not_configured`, provider failures are `failed`, and useful non-provider output is `fallback`.
- Never send provider credentials or raw uploaded videos to the mobile bundle or external providers.
- Agnes receives at most three bounded evidence moments and only derived frames.
- The deterministic Observation gate controls whether Timing and Formation may run.
- OpenAI tools are read-only, typed, session-scoped, and cannot accept arbitrary SQL, paths, or model names.
- Zo visibility is `private` or `unlisted`; report publishing must not depend on reminder creation.
- Do not upgrade Expo SDK 54 or add provider SDKs to the mobile app.
- Live provider tests require explicit opt-in flags and must not run in the default unit suite.
- All new provider paths must leave the existing no-key deterministic path working.
